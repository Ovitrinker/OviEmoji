# Settings for CurseForge and Modrinth

The form fields filled in by hand when creating the project. Texts: `description.md`.
Project image: `oviemoji-logo.png` (512 × 512). Changelog: `changelog.md`.

## Both platforms

| Field | Value |
|---|---|
| Name | OviEmoji |
| Loader | Fabric |
| Minecraft versions | 1.21.11, 26.2, 26.3 |
| Dependency | Fabric API (required) |
| License | All Rights Reserved (see `LICENSE`) |
| Source code | https://github.com/Ovitrinker/OviEmoji |
| Issues | https://github.com/Ovitrinker/OviEmoji/issues |

The matching jar is uploaded for each Minecraft version, always **without** `-sources`:

| Jar | Game version |
|---|---|
| `oviemoji-1.0.0+1.21.11.jar` | 1.21.11 |
| `oviemoji-1.0.0+26.2.jar` | 26.2 |
| `oviemoji-1.0.0+26.3.jar` | 26.3 |
