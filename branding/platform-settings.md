# Einstellungen für CurseForge und Modrinth

Die Formularfelder, die man beim Anlegen des Projekts von Hand ausfüllt. Texte: `description.md`.
Projektbild: `oviemoji-logo.png` (512 × 512). Changelog: `changelog.md`.

## Beide Plattformen

| Feld | Wert |
|---|---|
| Name | OviEmoji |
| Loader | Fabric |
| Minecraft-Versionen | 1.21.11, 26.2, 26.3 |
| Abhängigkeit | Fabric API (erforderlich) |
| Lizenz | All Rights Reserved (siehe `LICENSE`) |
| Quellcode | https://github.com/Ovitrinker/OviEmoji |
| Issues | https://github.com/Ovitrinker/OviEmoji/issues |

Pro Minecraft-Version wird das passende Jar hochgeladen, jeweils **ohne** `-sources`:

| Jar | Spielversion |
|---|---|
| `oviemoji-1.0.0+1.21.11.jar` | 1.21.11 |
| `oviemoji-1.0.0+26.2.jar` | 26.2 |
| `oviemoji-1.0.0+26.3.jar` | 26.3 |
